# 个人工作台需求文档

## 1. 项目概述

### 1.1 项目定位

个人工作台是一个面向个人开发者的本机 Web 应用，用于统一管理软件项目、项目任务、个人知识库和技术笔记。

第一版运行在本机 `localhost` 环境，优先解决个人项目推进过程中的信息分散问题，包括：

- 软件项目的基本信息沉淀
- 项目任务的看板式管理
- 技术笔记的分类、标签和 Markdown 记录
- 项目、任务、笔记之间的基础关联和检索

### 1.2 使用对象

第一版仅面向项目所有者本人使用。

不包含以下能力：

- 用户注册
- 用户登录
- 多用户协作
- 团队空间
- 角色权限
- 公网访问安全体系

### 1.3 第一版目标

第一版 MVP 以“项目 + 任务”为核心，知识库作为辅助能力。

成功标准：

- 可以创建和维护软件项目
- 可以在项目下创建任务，并通过看板状态推进任务
- 可以记录 Markdown 技术笔记，并通过分类和标签管理
- 可以通过标题、分类、标签搜索或筛选项目、任务、笔记
- 可以通过 Vue 前端页面完成核心工作流
- 可以在本机 MySQL `workstation` 数据库中持久化数据

## 2. MVP 功能范围

### 2.1 项目模块

项目模块用于记录个人软件项目的基础信息和开发上下文。

项目需要支持：

- 创建项目
- 查看项目列表
- 查看项目详情
- 编辑项目信息
- 删除项目
- 更新项目状态
- 查看项目关联任务
- 查看项目关联笔记

项目字段：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 名称 | 项目名称 | 是 |
| 描述 | 项目简介、目标或背景 | 否 |
| 状态 | 项目当前状态 | 是 |
| 仓库地址 | Git 仓库或代码托管地址 | 否 |
| 技术栈 | 项目使用的语言、框架、数据库等 | 否 |
| 运行说明 | 本地启动、依赖、端口、注意事项 | 否 |
| 创建时间 | 系统生成 | 是 |
| 更新时间 | 系统生成 | 是 |

项目状态建议：

- `PLANNING`：规划中
- `ACTIVE`：进行中
- `PAUSED`：已暂停
- `COMPLETED`：已完成
- `ARCHIVED`：已归档

### 2.2 任务模块

任务模块用于管理项目推进过程中的具体事项，第一版采用看板流转方式。

任务需要支持：

- 创建任务
- 查看任务列表
- 按项目查看任务
- 按状态查看任务看板
- 查看任务详情
- 编辑任务
- 删除任务
- 更新任务状态
- 更新任务优先级
- 更新任务截止日期

任务字段：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 标题 | 任务名称 | 是 |
| 描述 | 任务背景、实现说明或备注 | 否 |
| 所属项目 | 任务关联的项目 | 是 |
| 状态 | 看板流转状态 | 是 |
| 优先级 | 任务重要程度 | 是 |
| 截止日期 | 任务计划完成日期 | 否 |
| 创建时间 | 系统生成 | 是 |
| 更新时间 | 系统生成 | 是 |

任务状态建议：

- `TODO`：待办
- `IN_PROGRESS`：进行中
- `DONE`：已完成

任务优先级建议：

- `LOW`：低
- `MEDIUM`：中
- `HIGH`：高

第一版不包含：

- 子任务
- 工时记录
- 任务提醒
- 日历视图
- 循环任务

### 2.3 知识库与技术笔记模块

知识库模块用于记录个人技术笔记、项目经验、问题排查过程和学习资料。

笔记需要支持：

- 创建 Markdown 笔记
- 查看笔记列表
- 查看笔记详情
- 编辑笔记
- 删除笔记
- 按分类筛选笔记
- 按标签筛选笔记
- 将笔记关联到项目
- 创建和维护分类
- 创建和维护标签

笔记字段：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 标题 | 笔记标题 | 是 |
| 内容 | Markdown 格式正文 | 是 |
| 分类 | 笔记所属分类 | 否 |
| 标签 | 笔记标签，可多个 | 否 |
| 关联项目 | 笔记关联的软件项目 | 否 |
| 创建时间 | 系统生成 | 是 |
| 更新时间 | 系统生成 | 是 |

分类字段：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 名称 | 分类名称 | 是 |
| 描述 | 分类说明 | 否 |
| 创建时间 | 系统生成 | 是 |
| 更新时间 | 系统生成 | 是 |

标签字段：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 名称 | 标签名称 | 是 |
| 创建时间 | 系统生成 | 是 |
| 更新时间 | 系统生成 | 是 |

第一版不包含：

- 双链笔记
- 笔记关系图
- 正文全文搜索
- 富文本编辑器
- 附件管理
- 笔记版本历史

### 2.4 搜索与筛选

第一版搜索能力以简单可靠为目标。

需要支持：

- 按项目标题搜索项目
- 按任务标题搜索任务
- 按笔记标题和正文搜索笔记
- 按分类筛选笔记
- 按标签筛选笔记
- 在项目详情中查看该项目关联的任务和笔记

第一版不要求搜索以下内容：

- 笔记正文
- 任务描述
- 项目运行说明
- 附件内容

## 3. 页面需求

### 3.1 首页 / 工作台概览

首页用于快速了解当前工作状态。

页面内容：

- 进行中的项目数量
- 待办任务数量
- 进行中任务数量
- 最近更新的项目
- 最近更新的笔记
- 全局搜索入口

### 3.2 项目列表页

项目列表页用于浏览和管理所有项目。

页面能力：

- 展示项目名称、状态、技术栈、更新时间
- 支持按标题搜索
- 支持按状态筛选
- 支持创建项目
- 支持进入项目详情

### 3.3 项目详情页

项目详情页用于查看单个项目的完整上下文。

页面内容：

- 项目基础信息
- 仓库地址
- 技术栈
- 运行说明
- 项目关联任务
- 项目关联笔记

页面能力：

- 编辑项目
- 删除项目
- 更新项目状态
- 新建该项目下的任务
- 新建或关联该项目下的笔记

### 3.4 任务看板页

任务看板页用于推进项目任务。

页面内容：

- `待办` 列
- `进行中` 列
- `已完成` 列
- 每个任务卡片展示标题、优先级、截止日期、所属项目

页面能力：

- 创建任务
- 编辑任务
- 删除任务
- 修改任务状态
- 按项目筛选任务
- 按优先级筛选任务

### 3.5 笔记列表页

笔记列表页用于浏览技术笔记。

页面能力：

- 展示笔记标题、分类、标签、更新时间
- 支持按标题搜索
- 支持按分类筛选
- 支持按标签筛选
- 支持创建笔记
- 支持进入笔记详情或编辑页

### 3.6 笔记编辑页

笔记编辑页用于创建和维护 Markdown 技术笔记。

页面能力：

- 编辑标题
- 编辑 Markdown 正文
- 选择分类
- 选择多个标签
- 选择关联项目
- 保存笔记

第一版不要求实时预览，但可以预留后续扩展空间。

### 3.7 分类与标签管理页

分类与标签管理页用于维护知识库组织方式。

页面能力：

- 创建分类
- 编辑分类
- 删除分类
- 创建标签
- 编辑标签
- 删除标签

## 5. 数据关系

### 5.1 核心实体

- `Project`：软件项目
- `Task`：项目任务
- `Note`：技术笔记
- `Category`：笔记分类
- `Tag`：笔记标签

### 5.2 实体关系

- 一个项目可以拥有多个任务
- 一个任务必须属于一个项目
- 一个项目可以关联多篇笔记
- 一篇笔记可以不关联项目
- 一篇笔记最多属于一个分类
- 一个分类可以拥有多篇笔记
- 一篇笔记可以拥有多个标签
- 一个标签可以被多篇笔记使用

### 5.3 删除规则

第一版采用明确可理解的删除规则：

- 删除项目时，如果项目下存在任务，不允许直接删除
- 删除项目时，如果项目下只存在关联笔记，允许删除项目，并清空笔记的项目关联
- 删除分类时，如果分类下存在笔记，不允许直接删除
- 删除标签时，允许删除标签，并移除笔记与该标签的关联
- 删除任务不影响项目
- 删除笔记不影响项目、分类、标签

## 6. 验收标准

### 6.1 项目验收

- 可以成功创建项目并持久化到数据库
- 项目列表能展示名称、状态、技术栈、更新时间
- 项目详情能展示仓库地址、技术栈、运行说明
- 可以编辑项目信息
- 可以更新项目状态
- 删除项目时遵循删除规则

### 6.2 任务验收

- 可以在项目下创建任务
- 任务可以设置标题、描述、优先级、截止日期
- 任务可以在 `待办`、`进行中`、`已完成` 状态之间流转
- 任务看板能按状态分列展示
- 可以按项目筛选任务
- 可以按优先级筛选任务

### 6.3 笔记录入验收

- 可以创建 Markdown 笔记
- 可以编辑 Markdown 内容
- 可以为笔记设置分类
- 可以为笔记设置多个标签
- 可以将笔记关联到项目
- 笔记详情能展示保存后的 Markdown 内容

### 6.4 搜索筛选验收

- 可以按标题搜索项目
- 可以按标题搜索任务
- 可以按标题和正文搜索笔记
- 可以按分类筛选笔记
- 可以按标签筛选笔记
- 项目详情能展示关联任务和关联笔记

### 6.5 边界验收

- 项目列表为空时，页面有空状态
- 任务看板为空时，每个状态列有空状态
- 笔记列表为空时，页面有空状态
- 任务未设置截止日期时，页面不显示异常占位
- 笔记未设置标签时，页面不显示异常占位
- 删除被限制时，系统返回明确错误信息

### 6.6 前端验收

- Vue 前端可以通过 REST API 获取和展示项目、任务、笔记、分类、标签数据
- Vue 前端可以完成项目、任务、笔记的新增、编辑、删除主流程
- Vue 前端可以完成任务看板状态流转
- Vue 前端可以完成笔记分类、标签、关联项目的选择和保存
- Vue 前端路由可以覆盖首页、项目列表、项目详情、任务看板、笔记列表、笔记编辑、分类与标签管理页面
- 前后端本地联调时，页面请求地址、端口和跨域配置清晰可配置

## 7. 技术约束

### 7.1 后端

- 基于 Spring Boot
- 使用 REST JSON API
- 使用 MyBatis 访问数据库
- 使用 MySQL 持久化数据
- 数据库默认名称为 `workstation`
- 配置通过 `.env` 或环境变量提供，不在配置文件中明文保存密码

### 7.2 前端

- 基于 Vue 构建单页 Web 应用
- 使用 Vue Router 管理页面路由
- 使用 REST JSON API 与 Spring Boot 后端交互
- 第一版需要包含 Web 页面
- 页面以工作台工具为定位，优先保证清晰、稳定、可快速操作
- 不做营销首页
- 不做移动端专项适配，但基础布局应避免在常见窗口尺寸下不可用
- 前端开发环境需要支持配置后端 API 地址，避免在代码中硬编码环境差异

### 7.3 安全与部署

- 第一版仅面向本机 `localhost` 使用
- 不做登录和权限
- 不做公网部署要求
- 不在 Git 仓库中提交真实 `.env`
